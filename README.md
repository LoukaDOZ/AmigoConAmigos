# AmigoConAmigos

Gamble With Your Friend mod to play Amigo. Amigo is a french game of chance made by FDJ®.

It uses [BepInEx by BepInEx](https://thunderstore.io/c/gamble-with-your-friends/p/BepInEx/BepInExPack/) and [MoreGames by Syd4r](https://thunderstore.io/c/gamble-with-your-friends/p/Syd4r/MoreGames/).

### Installation

Install through [Thunderstore Mod Manager](https://thunderstore.io/c/gamble-with-your-friends/p/Kit2Soin/AmigoConAmigos/).
